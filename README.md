## Сбор информации о компьютере

### Цель работы

Разработать программу на Python для автоматизированного сбора информации
о текущей операционной системе и аппаратных характеристиках компьютера
с последующим сохранением результатов в формате JSON.

## Используемые технологии

- Python 3
- `platform` — получение информации об операционной системе,
  архитектуре и процессоре.
- `os` — получение количества логических процессоров.
- `psutil` — получение информации об оперативной памяти и дисках.
- `json` — сохранение собранной информации в JSON-файл.

### Внешние модули

В работе используется модуль `psutil`.

`psutil` выбран для получения системной информации, поскольку он
предоставляет удобный кроссплатформенный интерфейс для работы
с аппаратными ресурсами компьютера. С его помощью программа может
получать информацию об оперативной памяти, дисках и других системных
ресурсах без необходимости использовать отдельные команды для каждой
операционной системы.
